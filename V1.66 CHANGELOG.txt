【移动端弹窗底部空白修复 — 本次核心更新】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📱 弹窗 Flex 布局修复 (FIFAWorldCup.html)
  - 根因：.modal-box flex 列布局中，内容区使用 flex: 1 1 auto（以内容尺寸为基准）
  - 修复：flex: 1 1 0% — 忽略内容固有尺寸，精确填满 h3 下方剩余空间
  - 新增 #summaryContent 到 flex-fill 列表（此前遗漏）
  - #rulesIframe 增加 overflow-y: auto
  - .modal-box 溢出策略从 hidden → auto（兜底滚动）

📱 完整阵容弹窗 V3a 覆盖修正 (squadmodal.js + FIFAWorldCup.html)
  - 根因：V3a 杂志排版注入 overflow:visible !important 覆盖移动端 flex 布局
  - 修复：@media (max-width: 480px) 恢复 overflow-y:auto + 适当内边距
  - @media (min-width: 481px) 保留桌面端 V3a 原有布局
  - 移动端 V3a-Hero 垂直排列、浮动卡片 position:static 自然流式
  - #列宽压缩至 22px、标签间距缩小（5个标签约310px，无需滑动）
  - 表格 max-height:none → 由 flex 布局接管

📱 球员详情弹窗全面移动端优化 (engine.js)
  - 头部重构：头像 56×56，名称拆分为中文名(nameMain) + (EnglishName)(nameEn) 独立行
  - 六格信息网格：3列→2列，padding 压缩至 10px/6px，标签字号 0.5rem
  - 出生日期 ↔ 体重 交换位置
  - 生涯/荣誉标题左 padding 24px→4px，贴近边框
  - 生涯表格字号 0.6rem，padding 5px/4px
  - 荣誉/伤病列表 padding 4px 8px，字号 0.62rem
  - 卡片容器 max-height: 92vh，整体可滚动
  - 🔧 热修复：切除无效 CSS :contains('生涯') 伪类 → 修复 JS 语法报错
